## ما يحدث بعد التثبيت

1. **الدخول:** حساب المتجر الذي أنشأه الأدمن (`/mobile/login` عبر البوابة). أول دخول يفرض تغيير
   كلمة المرور المؤقتة.
2. **تسجيل التركيب:** يظهر طلب الجهاز في لوحة الأدمن قسم «اعتماد هواتف المتجر». قبل الاعتماد
   يبقى الدفتر بانتظار الموافقة، ويعرض التطبيق السبب بدل أن يفشل صامتًا.
3. **الدفتر المعتمد:** بعد الاعتماد تُقرأ النسخة، ويُرخَّص الجهاز سبعة أيام للعمل دون اتصال،
   وقد تُكتب الإدخالات وتُرفع مع إيصالاتها.

التفاصيل خطوة بخطوة في `delivery/SADID_RUNBOOK_AR.md`.

## التثبيت

يدويًا: انقل الملف إلى الهاتف، افتحه، واسمح بالتثبيت من هذا المصدر لحظة التثبيت فقط.

عبر ADB:

```sh
adb install -r Sadad-2.5.11-server-debug.apk
# Android 13+ يحتاج إذن الإشعارات لتذكيرات الاستحقاق:
adb shell pm grant com.sadad.app android.permission.POST_NOTIFICATIONS
```

لا تعارض مع نسخة الاختبار المستقلة: معرّفها مختلف (`com.sadad.app.test.offline`)، فيمكن أن
تتعايشا على الجهاز نفسه.

## الحدود المعروفة (اقرأها قبل التوزيع)

- **موقّعة بمفتاح التطوير**، مثل حزم 2.5.11 السابقة. ليست توقيع إنتاج.
- **`usesCleartextTraffic=true`** وحقل عنوان الخادم **قابل للتعديل**، لأنها نسخة `debug`.
  إصدار الإنتاج (`assembleServerRelease` بمفاتيح `SADAD_KEYSTORE_*`) يقبل العنوان المدمج وحده.
- **لم تُثبَّت على هاتف فعلي** من بيئة البناء هذه: لا جهاز متصل. التحقق كله أدناه جرى دون هاتف.
